# 隐私与发布

发布目录采用允许列表，只保留工程代码、说明和明确保留的媒体。它不携带旧 `.git` 历史、个人 Git 配置、账号存储、`.local`、环境文件、密钥、日志、缓存或测试截图。

所有安装路径和用户名均从当前系统解析；不写入特定电脑的姓名、用户目录、邮箱或会话标识。项目不需要 API 密钥。第三方代码的必要版权声明及媒体 AI 来源标记保留。

运行 `python3 scripts/privacy_check.py` 可检查文本和媒体元数据。`--deny-term` 可添加只在本次检查中使用的私人姓名或标识；结果不会回显命中内容。运行 `python3 scripts/package.py` 时必须先通过同样的检查，然后生成采用固定时间戳的源码 ZIP 及文件哈希清单。

检查是规则匹配，不能证明所有未知秘密都不存在，也不对画面内容执行 OCR。当前保留的媒体为角色插图和动画；更换媒体时需同时检查画面、音轨、元数据及素材许可。后续提交的作者和公开账号由自己的 Git/GitHub 设置控制。
